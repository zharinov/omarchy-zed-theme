## Install

```bash
omarchy plugin add https://github.com/zharinov/omarchy-zed-theme.git --enable
```

## Update

```bash
omarchy plugin update io.github.zharinov.omarchy-zed-theme
```

## Uninstall

```bash
omarchy plugin remove io.github.zharinov.omarchy-zed-theme
```
